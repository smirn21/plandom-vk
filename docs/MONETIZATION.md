# Монетизация (ЮKassa)

Технически — **ЮKassa** (карта, СБП, автоплатежи). «ЮMoney» для пользователя = те же способы оплаты через кассу.

## Варианты модели

### A. Как Agrobotik (подписка + пакеты) — baseline

| Тариф | Цена | Что даёт |
|-------|------|----------|
| Free | 0 | 1 проект: схема + 1 комната «меблировано» |
| PRO месяц | 149–299 ₽ | N проектов / месяц, все комнаты, без водяного знака |
| PRO год | ~10× месяц со скидкой | то же |
| Пакет «3 проекта» | 199 ₽ | разово, без подписки |
| Пакет «10 проектов» | 499 ₽ | для активного ремонта |

**Плюсы:** знакомая механика, код из Agrobotik почти 1:1.  
**Минусы:** дизайн-проекты реже, чем «спросил про цветок» — conversion может быть ниже.

### B. Оплата за проект (рекомендую протестировать)

| Продукт | Цена |
|---------|------|
| Схема квартиры | 99 ₽ |
| Квартира полностью (все комнаты) | 399 ₽ |
| Дом 1–2 этажа | 699 ₽ |
| Доп. комната / вариант стиля | 49 ₽ |

Free: только **превью низкого разрешения** или watermark.

**Плюсы:** понятно пользователю («плачу за результат»).  
**Минусы:** сложнее UX (корзина / upsell).

### C. Freemium + PRO «безлимит черновиков»

- Free: неограниченно **черновики схем** (дешёвый SVG).
- Платно: **HD рендер комнат**, PDF, несколько стилей.

**Плюсы:** низкий COGS на free.  
**Минусы:** слабее wow на первом касании.

### D. Гибрид (рекомендация для A/B)

- **Free:** 1 полный мини-проект (как сейчас в таблице A).
- **Разовая покупка** «вся квартира» 349 ₽.
- **PRO 249 ₽/мес** — 5 полных проектов + приоритетная очередь.

---

## Unit economics (ориентир)

При ~15–40 ₽ COGS на полный проект (LLM + 3–5 картинок):

- Free лимит должен **не превышать ~20–30 ₽** на пользователя.
- Маржа с разового 349 ₽ ≈ 70–85% до рекламы VK.

## Реализация в коде

- Тот же `YooKassaClient`, таблица `payments`.
- Типы: `subscription`, `package`, `project_unlock` (новое для варианта B).
- Webhook / polling pending — как `vk/main.py` Agrobotik.
