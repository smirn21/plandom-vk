## Итоговая сетка (гибрид)

| Тариф | Цена | Содержание |
|-------|------|------------|
| Free | 0 | Схема + 1 комната HD, остальное с watermark, без PDF |
| Квартира | 399 ₽ | Все комнаты + PDF + PNG в чат |
| Дом | 799 ₽ | 1–2 этажа, PDF + PNG |
| Доп. вариант | 99 ₽ | Стиль или комната в существующем проекте |
| PRO месяц | 399 ₽ | 3 полных проекта/мес, PDF, без watermark, черновики схем ∞ |
| PRO год | 3990 ₽ | то же, ~−17% |

Промо: первый месяц PRO **249 ₽** (опционально, не базовая цена).

## Техника

- Отдельный **shop_id** ЮKassa.
- `YooKassaClient` + polling pending payments (как Agrobotik).
- PDF: генерируем на сервере, отдаём signed URL или VK doc attachment.
