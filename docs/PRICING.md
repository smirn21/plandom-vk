# Тарифы ПланДом — что означает каждая цена

## Коротко

| Что покупает пользователь | Цена | Смысл |
|---------------------------|------|--------|
| **Free** | 0 ₽ | Попробовать: схема + 1 комната, с ограничениями |
| **Квартира** (разово) | **399 ₽** | Полный результат: все комнаты + PDF |
| **Дом** (разово) | **799 ₽** | То же для дома 1–2 этажа |
| **Доп. вариант** | **99 ₽** | Ещё один стиль или ещё одна комната в том же проекте |
| **PRO** (месяц) | **399 ₽** | Для активного ремонта: несколько проектов выгоднее разовых |

PNG приходит в чат VK, PDF — ссылка на скачивание после оплаты (или в PRO).

---

## Что входит в «проект»

**Проект** — одна квартира или один дом, который пользователь описал в wizard (или по фото комнаты — ветка «одна комната»).

В **полном проекте**:
1. **Планировка** — SVG/PNG схема комнат и подписями.
2. **Обстановка** — AI-рендер по каждой комнате (или по выбранным).
3. **PDF-комплект** — план + листы по комнатам для сохранения/печати.

**Free (пробный):**
- схема квартиры/дома — да;
- **1 комната** в HD — да;
- остальные комнаты — превью с watermark или blur;
- PDF — нет (только PNG в чате).

Так пользователь видит качество, но за «весь объект» платит отдельно или берёт PRO.

## Почему разовые цены именно такие

### Квартира — 399 ₽

- Типичный запрос: 3–5 комнат → 1 LLM-сессия + 3–5 картинок + PDF.
- **Себестоимость (COGS)** на один полный проект: ориентир **40–80 ₽** (Grok + генерация изображений, зависит от числа комнат).
- **399 ₽** ≈ 80–90% маржи до рекламы — нормально для digital-товара.
- Психологически: меньше 500 ₽ — «можно попробовать на ремонт»; больше 500 ₽ — уже «дорого за картинку» без бренда.

### Дом — 799 ₽

- Больше комнат, этажность, сложнее план → выше COGS и время.
- Примерно **×2 от квартиры**, не ×3: чтобы дом не казался «недостижимым» на старте.

### Доп. вариант — 99 ₽

- Тот же проект, другой стиль («лофт» вместо «сканди») или ещё одна комната в HD.
- Дешёвая upsell после первой покупки; COGS одной картинки ~10–20 ₽.

## PRO — почему не 249 ₽, а 399 ₽/мес

**249 ₽** в черновике был **ценой для первых подписчиков** (низкий порог, как у Agrobotik 149 ₽), но для ПланДом он **ломает логику**:

| Проблема 249 ₽ | Объяснение |
|----------------|------------|
| Дешевле одной квартиры | Разово квартира 399 ₽, а PRO 249 ₽ за **3 проекта** — подписчик платит меньше за один проект, чем разовый покупатель → никто не покупает разово. |
| Не покрывает «тяжёлых» users | Кто делает 3 полных квартиры за месяц = COGS ~120–240 ₽ + поддержка → на 249 ₽ маржа слишком тонкая. |
| Другой продукт, не Agrobotik | Agrobotik — текстовые ответы, дешёвле. ПланДом — **картинки + PDF**, unit economics другие. |

**Итоговое предложение: PRO = 399 ₽/мес**

| | PRO 399 ₽/мес | Разово квартира 399 ₽ |
|--|----------------|------------------------|
| Полных проектов | **3 в месяц** | 1 |
| PDF | да | да |
| Watermark | нет | нет |
| Черновики схем | безлимит (только SVG, без AI-рендера) | — |

**Логика для пользователя:**
- Нужна **одна** квартира → плати **399 ₽ разово**.
- Идёт **активный ремонт** (несколько вариантов, квартира + дача) → **PRO выгоднее** (3×399 = 1197 ₽ разово vs 399 подписка).

**249 ₽** можно вернуть как **промо первый месяц** («-38%»), но не как постоянную цену.

## Сравнение с Agrobotik

| | Agrobotik PRO ~149 ₽ | ПланДом PRO 399 ₽ |
|--|----------------------|-------------------|
| Что отдаём | Текст + анализ фото | План + несколько AI-картинок + PDF |
| COGS за «запрос» | низкий | высокий |
| Частота использования | часто, мелкие вопросы | редко, но тяжёлые генерации |

ПланДом **не должен** быть дешевле Agrobotik по подписке — он дороже в производстве.
